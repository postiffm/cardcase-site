# Cardcase website

Public pages for the Cardcase Android app, served by GitHub Pages at
https://postiffm.github.io/cardcase-site/

- `index.html` — home page
- `privacy-policy.html` — privacy policy (linked from the Google Play listing)

The app's source code is kept privately; the master copy of the privacy policy lives in its
`store/` folder and is copied here when it changes.
